01 — OVERVIEW

Principles that shape every pixel

Cascade is built lean-core first: the grid and the waterfall are the product; everything else stacks on top. The interface reflects that discipline — it earns density, it never hides cost, and it treats an async cell as a first-class citizen.

Density is a feature

This is an operator tool. Rows per screen, fast scanning, and keyboard flow beat marketing whitespace. Speed under ~150ms is a design constraint, not an aspiration.

The waterfall is visible

Provider fall-through is the core mechanic. The UI shows the order, where a row fell through, and which step supplied each value — never a black box.

State, always legible

Every enrichment cell wears its status: Queued, Running, Success, Empty, Failed, or Cached. Colour and form carry meaning before a single word is read.

Cost is never hidden

Credits and provider spend are surfaced before a run, during a run, and in provenance after. The amber money accent means one thing everywhere: this consumes budget.

04 — FOUNDATIONS

The status system

The single most important pattern in the product. Every asynchronous cell — enrichment, AI, agent, HTTP — moves through this exact state machine. Colour, a dot, and one word. Nothing else competes with it.

Queued#8698A4

Accepted, waiting for a worker. Neutral slate — present but inert. No spend yet.

Running#2FE6C8

A provider call is in flight. Brand aqua with a pulsing dot — the only status that animates.

Success#38D08C

A usable value was written. Green. Provenance records which step and provider supplied it.

Empty#F5B544

No data found — distinct from failure. Amber, not red. Consumed no credit if input was missing.

Failed#F2666B

Errored after retries. Red. Hover reveals the reason; the prior value is left intact.

Cached#AB8CFB

Served from cache within its freshness window. Violet — the "you didn't pay for this" state.

08 — FOUNDATIONS

Motion

Motion follows water — it eases out, it flows downward, and it stays out of the way. The running state is the only persistent animation in the product; everything else is a brief, purposeful transition. All of it respects prefers-reduced-motion.

--ease
cubic-bezier(.22,.61,.36,1)

Default flow — decelerating ease-out for reveals and hovers.
